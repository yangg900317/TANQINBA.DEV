吉他谱播放器
==============

双击「启动.bat」打开。这是一个在电脑上跟谱练习的本地播放器：六线谱和五线谱对齐，播放时红线跟着走，当前音符变红，指板同时亮起。

它不登录弹琴吧，也不下载网站上的曲谱。安装包里的音色库、加密谱和示例网页里的歌曲都没有放进来。自带的《练习曲一》是一段原创练习，用来试听。

播放
----
空格          播放 / 暂停
单击乐谱      从点击的位置开始
Home          回到开头
速度、变调    只改变试听。谱面品位和指板不动，方便对原谱
节拍器        每拍一声，小节第一拍更重
预备拍        正式出声前先给一个小节
跟谱滚动      光标走到下一行时自动翻页
旋律          播放谱上写下的音
伴奏          按当前和弦扫弦或分解，可选民谣、摇滚、分解、华尔兹
设 A / 设 B   循环这一段。也可以 Shift+单击设 A，Ctrl+单击设 B
Esc           取消循环
Ctrl+滚轮     缩放乐谱

打开自己的谱
------------
点右上角「打开乐谱」，选择 JSON 文件。也可以把文件拖进窗口。
示例在 scores\练习曲一.json，复制一份再改最方便。

一份最短的谱：

{
  "title": "我的练习",
  "subtitle": "C调吉他弹唱谱",
  "artist": "自己",
  "key": "C",
  "beatsPerMeasure": 4,
  "beatUnit": 4,
  "tempo": 80,
  "tuningMidi": [64, 59, 55, 50, 45, 40],
  "measures": [
    {
      "label": "主歌",
      "chords": [{"beat": 0, "name": "C"}],
      "notes": [
        {"beat": 0, "string": 2, "fret": 1, "duration": 1, "lyric": "你"},
        {"beat": 1, "string": 1, "fret": 0, "duration": 1, "lyric": "好"}
      ]
    }
  ]
}

弦号 1 是最细的高音弦，6 是最粗的低音弦。
beat 是这一拍在小节里的位置，0 是第一拍。
duration 用拍做单位：1 是四分音符，0.5 是八分音符，1.5 是附点四分音符。
tuningMidi 从 1 弦写到 6 弦，上面这组是标准定弦。
key 用 C、G、D、F、Bb 这种写法。和弦名可以用 C、Em、G7、F#m 这类常见名字。
